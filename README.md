# BioFAIR 2027 Workflow Interoperability Sprint

**Hybrid sprint bringing together contributors from Bioconductor, Galaxy, Nextflow, nf-core, WDL and related workflow communities.**

## Event details

* **When:** 4 February 2027
* **Where:** Oxford, UK
* **Format:** Hybrid (Microsoft Teams)
* **Venue:** Jesus College

## Overview

The BioFAIR Workflow Interoperability Sprint brings together developers, users, infrastructure providers and community leaders from across the bioinformatics workflow ecosystem.

The event focuses on making Bioconductor methods available across different computing platforms and workflow ecosystems, including:

* Galaxy
* Nextflow / nf-core
* WDL
* TES and workflow execution services
* Related open-source infrastructure projects

The sprint will introduce [BiocJobs](https://github.com/almahmoud/BiocJobs), an approach that enables analysis tasks to be defined alongside Bioconductor packages and automatically translated into formats supported by different workflow systems.

The day will start with a brief demonstration of how we've applied BiocJobs to an exemplar single-cell analysis workflow, using this as a practical example to illustrate the process.

The main focus of the day will be hands-on collaboration, helping participants apply the same approach to their own favourite Bioconductor tools and workflows, with support from contributors across the different communities.

We'll also set aside time to reflect on the outcomes of the sprint, discuss their broader implications, and identify next steps for dissemination and continued collaboration across the communities involved.

## Goals

Goals for participants:

- Bring Bioconductor tools to your favourite platform(s)
- Gain hands-on experience contributing to open-source scientific software
- Connect with the wider data science community
- Improve interoperability between workflow platforms
- Champion FAIR values and reproducible workflows

Opportunities to contribute to:

- AI-readiness for workflow generation and automation
- Galaxy tool and workflow development
- Nextflow / nf-core module and pipeline development
- WDL integration and testing
- documentation and community resources

This sprint is connected to the BioFAIR Pathfinder project "Connecting Bioconductor, Galaxy, and nf-core: FAIR, AI-ready workflows and training for single-cell analysis", led by Kevin Rue-Albrecht.
